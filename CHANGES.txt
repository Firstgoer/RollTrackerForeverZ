2.2.0 - WoW: Forever support (Interface 16001, "Camelot")
- Addon renamed to RollTrackerForeverZ (folder, TOC files and SavedVariables)
- New RollTrackerForeverZ_Camelot.toc for the WoW: Forever client
- Fixed load error: the classic Loot Rolls window (LootHistoryFrame) does not exist
  on Forever; RTC now drives the modern GroupLootHistoryFrame
- Fixed load error: CharacterFrameTabButtonTemplate is not loaded on Forever;
  tabs use PanelTabButtonTemplate there
- Item info, item class and chat sending use C_Item / C_ChatInfo
- Unit tooltips (player notes) use TooltipDataProcessor instead of OnTooltipSetUnit
- Chat payloads that are secret during chat messaging lockdown (encounters, M+,
  rated PvP) are skipped instead of erroring; announcements fall back to the
  local chat frame while sending is locked
- Loot tracker waits for uncached items instead of erroring
- Note popup uses dialog:GetEditBox(); chat focus uses ChatFrameUtil
- Hyperlinks in the loot list use SetItemRef
- Forever look: modern flat panel, title bar, close button and tabs; right-click
  menu uses the native Blizzard menu; addon compartment (minimap list) entry
- Forever port by Firstgoer, co-authored with Claude
