2.2.0 - WoW: Forever support (Interface 16001, "Camelot")
- Addon renamed to RollTrackerForeverZ (folder, TOC files and SavedVariables)
- New RollTrackerForeverZ_Camelot.toc for the WoW: Forever client
- Removed the "unsupported game version" fallback TOC (Forever-only package)
- Fixed load error: the classic Loot Rolls window (LootHistoryFrame) does not exist
  on Forever; RTC now drives the modern GroupLootHistoryFrame
- Fixed load error: CharacterFrameTabButtonTemplate is not loaded on Forever;
  tabs use PanelTabButtonTemplate there
- Item info, item class and chat sending use C_Item / C_ChatInfo
- Unit tooltips (player notes) use TooltipDataProcessor instead of OnTooltipSetUnit
- Chat payloads that are secret during chat messaging lockdown (encounters, M+,
  rated PvP) are skipped instead of erroring; announcements fall back to the
  local chat frame while sending is locked
- Pass button records your pass directly when solo or while chat is locked,
  instead of only printing "pass" to your chat window
- Loot tracker waits for uncached items instead of erroring
- Note popup uses dialog:GetEditBox(); chat focus uses ChatFrameUtil
- Hyperlinks in the loot list use SetItemRef
- Fixed Forever skin layering: border/title bar no longer cover the window content,
  close and title-bar buttons; roll list uses the modern thin scroll bar
- Forever look: roll list rebuilt as rows (class icon, name, roll; winner highlighted,
  striped rows, main/off spec and not-rolled sections) on an inset panel; loot and
  CSV tabs on inset panels; larger, evenly spaced button bar
- Forever look: modern flat panel, title bar, close button and tabs; right-click
  menu uses the native Blizzard menu; addon compartment (minimap list) entry
- Forever window redesign: winner row with gold highlight bar and checkmark,
  "tie" marker, dimmed out-of-range rolls, re-roll refresh icon, section counts,
  empty state; action bar [Announce][more v][clear] / [Roll][Off Spec][pass];
  "Not rolled" moved into the more-menu and a clickable "N waiting" status
- Guild rank shown in the smallest dim font after the name (truncated first)
- "N rolled" / "N waiting" moved into a header at the top of the roll list
  (the countdown bar appears there too); re-rolls no longer count twice
- Countdown shows the game's loot roll timer bar with seconds left
- Countdown button (clock) next to [Announce] for the raid leader and assistants
  (always shown when solo); click to start, click again to stop
- The game's resize handles: under the window (height) and on the right edge
  (width); the old invisible resize edges are gone on Forever
- Option: in a group, show [Announce] and the roll menu only to the leader
  and assistants (others get [Roll][Off Spec][clear][Pass])
- Pass button takes about a third of the row (Roll keeps two thirds) and shows
  its label when there is room
- Russian translation (ruRU); "pass" and "пас" are both recognised
- Custom texts from Options > Localization are now actually applied after /reload
- Forever port by Firstgoer, co-authored with Claude
